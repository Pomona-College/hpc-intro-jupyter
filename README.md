# Introduction to Jupyter Notebooks

Pomona College HPC Workshop Series

## Overview

This workshop teaches interactive computing with Jupyter Notebooks on Sagehen HPC cluster. Learners will explore notebook fundamentals, launch interactive Jupyter sessions through OnDemand, write Python code and visualizations, manage computational environments, and apply best practices for reproducible research.

## Episodes

1. **Introduction to Jupyter Notebooks**: Explore notebook benefits, anatomy of cells, and advantages for computational research
2. **Launching Jupyter on Sagehen HPC**: Access Jupyter through OnDemand, request compute resources, and understand cluster-based notebooks
3. **Notebook Basics**: Master cells, markdown, code execution, and notebook navigation
4. **Python in Notebooks**: Write executable code, create visualizations, and generate formatted output
5. **Managing Environments**: Create custom Python environments, install packages, and manage dependencies
6. **Best Practices**: Organize notebooks for reproducibility, document your work, and share results effectively

## Prerequisites

- Completion of Workshop 0: Introduction to HPC Systems (or equivalent HPC experience)
- Basic Python programming knowledge
- Sagehen HPC cluster account
- Familiarity with OnDemand portal (optional but helpful)

## Learning Objectives

After completing this workshop, learners will be able to:
- Understand Jupyter Notebook structure and benefits for interactive computing
- Launch JupyterLab on Sagehen through OnDemand
- Write and execute Python code within notebooks
- Create visualizations and formatted output
- Manage Python environments and packages
- Organize notebooks for reproducibility and sharing

## Target Audience

Researchers using Python for data analysis, visualization, and exploratory computing. Suitable for those transitioning from laptop-based work to cluster-based computing.

## Duration

Approximately 2.5 to 3 hours including hands-on exercises.

## Technical Requirements

- Sagehen HPC cluster account
- OnDemand portal access (https://ondemand.hpc.pomona.edu/)
- Web browser (Firefox, Chrome, Safari, or Edge)
- Internet connection
- Basic understanding of Python (import statements, functions, data structures)

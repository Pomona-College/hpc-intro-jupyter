## What You Need

Before the workshop, please verify the following:

### 1. Pomona College HPC Account

You need an active HPC account on the Sagehen cluster.

:::::::::::::::: callout

### Verify your account

1. Go to https://ondemand.hpc.pomona.edu/
2. Log in with your Pomona College username and password
3. Complete DUO authentication on your phone
4. If you see the OnDemand dashboard, you're ready!

If you can't log in:
- Verify your Pomona username (ask ITS Help Desk if unsure)
- Ensure DUO is registered (register at https://duo.pomona.edu/)
- Contact its-hpc@pomona.edu for account issues

:::::::::::::::::::::::::

### 2. Web Browser

You'll use your web browser to access JupyterLab. Ensure you have a modern browser:

- **Google Chrome** (recommended)
- **Firefox** (recommended)
- **Safari** (Mac)
- **Microsoft Edge** (Windows)

Avoid very old versions of Internet Explorer.

### 3. Internet Connection

Jupyter requires a persistent network connection to the cluster. Ensure:

- Stable WiFi or wired connection
- If on campus WiFi, make sure you're on "Pomona" network (not "Guest")
- Off-campus? VPN may be required (check with ITS Help Desk)

### 4. Basic Python Knowledge

This workshop assumes you know:

- Variables and data types (strings, numbers, lists)
- Simple functions and for loops
- How to read and understand error messages

If you're new to Python, we recommend completing a Python basics tutorial first. Good resources:

:::::::::::::::: callout

### Python Learning Resources

- **Codecademy Python Course** (interactive, free): https://www.codecademy.com/learn/learn-python-3
- **Python for Everybody** (comprehensive, free): https://www.py4e.com/
- **Kaggle Python Micro-Courses** (bite-sized, free): https://www.kaggle.com/learn/python

All assume no prior experience. Complete any of these and you'll be ready!

## Getting Help Before the Workshop

If you encounter issues:

**Can't access OnDemand:**
- Email: its-hpc@pomona.edu
- Subject: "Can't access OnDemand"
- Include: your Pomona username, error message (if any)

**Trouble with DUO:**
- Contact ITS Help Desk: (909) 621-8000 ext. 72777
- Or: https://www.pomona.edu/its/
- They handle DUO issues

**Browser problems:**
- Try a different browser (Chrome, Firefox)
- Clear browser cache (Ctrl+Shift+Delete / Cmd+Shift+Delete)
- Try in incognito/private mode

**Internet connectivity:**
- Try on campus WiFi or wired connection
- Off-campus? Contact ITS about VPN access

**Python knowledge gaps:**
- Check resources above for 1-2 hours of learning
- Basic Python is essential; reach out if you need guidance

## Troubleshooting Sagehen Access

If you can't access OnDemand:

**Check 1: Is OnDemand the right URL?**
- Correct: https://ondemand.hpc.pomona.edu/
- Wrong: ondemand.hpc.pomona.com (no "https")

**Check 2: Are you using the right username?**
- Pomona username (what you use for email)
- Not your full name
- Not "student" or generic names

**Check 3: Is DUO working?**
- Check your phone: Is DUO app installed and current?
- Is your device registered at https://duo.pomona.edu/?
- Try "Call me instead of code" if codes don't work

**Check 4: Is the cluster working?**
- Check cluster status: its-hpc@pomona.edu
- Rarely, Sagehen goes down for maintenance
- Status posted on cluster website

**Still stuck?**
- Email: its-hpc@pomona.edu
- Include:
  - Your Pomona username
  - Exact error message (copy-paste)
  - What you've already tried
  - Preferred contact method and time

## What Happens During the Workshop

The workshop is **hands-on and interactive**:

1. **First episode:** Lecture + discussion about Jupyter (15 min) + small exercise
2. **Subsequent episodes:** Lecture (20-40 min) + guided exercises (15-25 min)
3. **Each exercise:** You write code in JupyterLab on Sagehen and see results immediately
4. **Challenges:** Optional deeper exercises for those who want more challenge

You'll need:
- A web browser open to OnDemand
- JupyterLab launched (we'll do this in Episode 2)
- Time to type and think
